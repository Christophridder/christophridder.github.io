LabPro-test – kan browseren tale med LabPro-kassen?

Sådan tester du

  1. Brug Chrome eller Edge (Safari og Firefox kan ikke tale med USB-udstyr).
  2. Luk Logger Pro – ellers "optager" Logger Pro kassen, og browseren kan ikke få fat i den.
  3. Sæt LabPro til strøm (adapteren, ikke batterier) og sæt gerne et termometer i CH1.
  4. Prøv forbindelserne herunder én ad gangen – start med A. Tryk derefter på knapperne under Kommandoer.
  5. Tryk til sidst Kopiér log og send loggen til Claude – også hvis intet virker. Loggen fortæller præcis, hvad der skete.

A · USB-kablet (WebUSB)

LabPros eget USB-kabel direkte i computeren (evt. via USB-C-adapter).

B · USB som HID (WebHID)

Samme kabel – prøves, hvis A ikke kan "gøre krav" på kassen.

C · Seriel port (Web Serial)

LabPros runde serielle stik via seriel-til-USB-adapter. Kan også prøves med USB-kablet.

Kommandoer – ikke forbundet
