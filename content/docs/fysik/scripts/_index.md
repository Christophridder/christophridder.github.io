**Niveau: Fysik C–A** · **Emne: Browserprogrammer**

Små programmer, der kører direkte i browseren – intet skal installeres, og dine data bliver ikke uploadet.

| Program | Link | Kort forklaring |
|---|---|---|
| Videoanalyse | [Åbn](/videoanalyse.html) | Mål et objekts position frame for frame i en video og få (t, x, y)-data til grafer. Se [vejledning]({{< relref "/docs/fysik/Metoder/videoanalyse" >}}). |
| Lydanalyse | [Åbn](/lydanalyse.html) | Optag eller indlæs en lyd og se frekvensspektret (FFT): grundtone, overtoner og svævning. Se [vejledning]({{< relref "/docs/fysik/Metoder/lydanalyse" >}}). |
| Solvind | [Åbn](/solvind.html) | Solvinden gjort hørbar: hastighed → tonehøjde, tæthed → rytme, spektrum → farver. Se [forløbet]({{< relref "/docs/fysik/klima/solvind" >}}). |
