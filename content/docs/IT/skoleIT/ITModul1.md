## Trinene i modulet

| Trin | System | Hvad eleven skal kunne | Link |
|---|---|---|---|
| 1 | **ITS-login** (skolelogin) | Oprette adgang med MitID, notere brugernavn og vælge kode | [password.supportcenter.dk](https://password.supportcenter.dk/) |
| – | ITS-portalen | Skifte kode og acceptere regler | [portal.supportcenter.dk](https://portal.supportcenter.dk/) |
| 2 | **Trådløst net** | Acceptere ITS' regler og logge på netværket **ITS** (ikke ITS-Guest) | [portal.supportcenter.dk](https://portal.supportcenter.dk/) → Regler |
| 3 | **Office 365** | Installere skolens Office, også selvom de har en anden Office-pakke | [m365.cloud.microsoft/apps](https://m365.cloud.microsoft/apps/) |
| 3 | **OneDrive** | Logge på med skolekontoen. Et gammelt OneDrive fra grundskolen skal afkobles først | (i OneDrive-appen) |
| 4 | **Teams** | Installere appen og følge "Årgang 26 (1.g)" og "Generelt" | [teams.microsoft.com](https://teams.microsoft.com/v2/) |
| 5 | **Lectio** | Logge på med MitID | [lectio.dk/lectio/256](https://www.lectio.dk/lectio/256/) |
| 6 | **Authenticator** | Installere Microsoft Authenticator til login hjemmefra | [Microsofts vejledning](https://support.microsoft.com/da-dk/account-billing/download-microsoft-authenticator-351498fc-850a-45da-b7b6-27e523b8702a) |
| 7 | **Moodle** | Tilmelde sig "AP2026" med ITS-login *uden* @egaa-gym.dk. Virker kun på skolen | [moodle.egaa-gym.dk](https://moodle.egaa-gym.dk/) |

## Kendte problemer (til lærer og tekniker)

| Problem | Hvad vi gør |
|---|---|
| **Gammelt OneDrive** fra efterskole/folkeskole | Afkobl den gamle konto i OneDrive-appen (Mac: menulinjen → ⚙ → Indstillinger → Konto → *Fjern tilknytning til denne Mac*; Windows: proceslinjen → ⚙ → Indstillinger → Konto → *Fjern tilknytning til denne pc*). Log derefter på med skolekontoen. Teknikeren tager de svære tilfælde |
| **Mac kan ikke gemme på skrivebordet** | Skrivebordet ligger ofte i iCloud. Se [IT-modul 3 – Mac: iCloud og skrivebordet]({{< relref "ITModul3#icloud-og-skrivebordet" >}}) |
| Eleven kan ikke huske koden | Ny kode via [password.supportcenter.dk](https://password.supportcenter.dk/) med MitID |
