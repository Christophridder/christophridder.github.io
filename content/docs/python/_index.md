# Python i fysik og kemi

Python er et gratis programmeringssprog, som du kan bruge til databehandling, regression, grafer og beregninger i fysik og kemi. Du behøver ikke at kunne programmere i forvejen – det meste kan klares med de korte kodestumper (snippets) her på siderne.

**Kom i gang:**

1. **Bare prøv det:** Brug [Jupyter online]({{< relref "/docs/python/installation/jupyter-online" >}}) – intet skal installeres.
2. **På din egen computer:** Installér med [Anaconda]({{< relref "/docs/python/installation/anaconda" >}}) (nemmest) eller [VSCodium]({{< relref "/docs/python/installation/vscodium" >}}) (som din lærer bruger).
3. **Find en kodestump:** Gå til [Snippets]({{< relref "/docs/python/snippets" >}}), kopiér og ret tallene til.
