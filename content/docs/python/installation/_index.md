# Installation af Python

Vælg den løsning, der passer til dig:

| Løsning | Installation | Fordele | Ulemper |
|---|---|---|---|
| [Jupyter online]({{< relref "/docs/python/installation/jupyter-online" >}}) | Ingen | Virker med det samme, også på iPad/Chromebook | Filer gemmes kun i browseren – husk at downloade |
| [Anaconda]({{< relref "/docs/python/installation/anaconda" >}}) | Ca. 15 min | Alt er med fra start (Jupyter, NumPy, SciPy …) | Stor installation (flere GB) |
| [VSCodium]({{< relref "/docs/python/installation/vscodium" >}}) | Ca. 30 min | Let, moderne editor – både `.py` og `.ipynb` | Lidt mere opsætning |
